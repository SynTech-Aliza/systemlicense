# systemlicense

1. Open Command Prompt.

2. Type the following command and press Enter:

    DOS
    copy con .license
4. Paste your exact text into the prompt:

    Plaintext
    ====================================================================
                        SYSTEM LICENSE CERTIFICATE                        
             Copyright © 2025 — Trikee Corporation
                  Developed by Trikee Solutions
    ====================================================================
    
    License_Key: CRMIS-TGLN-2026-060526
    Client Name: Municipality of Tangalan
    Date Publish: 2026-06-25
    Host Name: localhost
    Host Username: Trikee_Server
    Host Password: @#Trikee_2023
    Database Name: tangalan_crmis
    
    ====================================================================
    NOTICE: Direct modification of this license file or its parameters 
    will render the system inactive. Registered to Municipality of Tangalan.
    
    Copyright © 2025 — Trikee Corporation. All Rights Reserved.
    Developed by Trikee Solutions.
    ====================================================================
   
5. Press Enter, then press Ctrl + Z on your keyboard, and press Enter again.
    
6. You will see 1 file(s) copied., and the .license file will be created in your current directory.
